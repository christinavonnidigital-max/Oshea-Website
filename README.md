# O'Shea SA Corporate Website

Corporate website for O'Shea SA, providing management systems certification, inspection, testing, and training services.

Built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

Prerequisites: Node.js and npm.

```sh
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Production build

```sh
npm run build
```

The production files are generated in `dist/`.

To preview the build locally:

```sh
npm run preview
```

## Enquiries and content

The contact form prepares an email to `info@oshea.co.za` in the visitor's email app. The visitor must send it there; the website does not submit or store enquiry fields. Visitors can also copy the recipient, subject and enquiry into webmail. If clipboard access fails, the form displays selectable text for manual copying. Email delivery requires the visitor's email app or webmail provider.

Service buttons preselect the enquiry's service. Privacy and website information pages describe the current workflow. See [content reference and confirmation](docs/content-confirmation.md) for the user-confirmed accreditation claims and statistics. There are no testimonials yet; testimonial sections have been removed.
